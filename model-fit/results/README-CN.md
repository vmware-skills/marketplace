# 评判结果

[English](README.md)

**目前没有任何真实候选模型的实测成绩。** `model-results.json` 的结果列表为空，状态是 `not_measured`，
不能把空列表理解为通过率 100%。

`controls-2026-11-12.json` 是人为编写的正确/故意错误输入，用来检查判定器；其中评审字段也是控制数据，
不代表真实人工评审过某个模型。`validation-2026-11-12.json` 记录独立环境下脚本测试的执行结果。
两者都不是模型成绩、自主运行、真机验证、授权或部署推荐。

希望提交模型评测的人可以：

1. 按上级 README 操作，在收集回答前保留 seal，提示和配置固定后才使用最终题；若看过保留题答案，要如实说明。
2. 在此目录新增带日期的、已脱敏的分组报告。记录实际模型/量化/框架/版本/parser/上下文，挂载范围，
   指令/工具/题目/协议哈希，重复数、失败、未测量项、人工评审来源和限制。不知道的保留 null。
3. 更新结果索引，指向该文件；不编造全局总分，不按参数量推断能力。离线调用计划的结果与未来真实自主运行分开。
4. 原始回复、operator 文件、服务地址、凭据、真实清单和客户内容不要提交，必要时仅保留在本机被忽略的 `out/`。

seal 由操作者保管，离线工具不能独立验真人员身份或证明每次回答重新生成。某组通过不等于生产安全、独立审批、
低失败率或最低成本；配置和契约发生实质变化后需要重测。
