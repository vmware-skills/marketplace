## 1. 问一个问题，沿着证据调查。

你的 VMware 环境，现在最需要关注什么？VMware Skills 把人工智能助手与专业技能和 MCP 工具连接起来，帮助工程师调查基础设施，找到下一步。

## 2. 一个家族，明确分工。

整个家族覆盖计算、网络、存储和可观测性。Pilot 编排工作流，领域服务连接各自的管理系统，Policy 提供共享策略检查、文本清洗和审计。建议从只读 Monitor 开始。

## 3. 问一句，看到实际调用返回的清单。

这里是实际调用的历史截图。清单返回了一个 vCenter、两台独立主机和十三台虚拟机。包含环境标识的备注列已经裁去。它展示当时查询范围内的结果，不是对当前环境重新做的一次清查。

## 4. 看健康，也保留判断边界。

健康截图把主机连接状态和严重告警放在同一个视图里。但历史状态不等于当前正在发生故障。决定下一步前，仍要核对观测时间，以及告警现在是否依然成立。

## 5. 需要变更时，先明确边界。

需要变更时，再选择对应领域技能和经过复核的工作流。VMware 原有权限与本地策略继续生效。破坏性工具有预览和确认门，但确认参数并不等于独立人工审批，回滚也只能尽力执行。

## 6. 最后，用审计记录追溯调用。

最后看审计记录。这是基于导出记录整理的助手汇总，列出时间、技能、工具、MCP 或 CLI 路径、状态和耗时。演示省略目标列，节选十四行。工具名称保留截图当时版本；完整性仍需核对原始记录。

## 7. 让日常运维，轻松一点。

VMware Skills 是社区开源项目，并非 VMware 或 Broadcom 官方产品。欢迎查看演示，试一个只读任务，分享有效的经验与需要改进的地方。如果它对你有用，也欢迎为家族门户点一颗星。
